## 🚀 Getting Started

Welcome to the Team-blog-back-end API! This guide will help you download and run the application easily. No technical knowledge is needed.

## 📥 Download & Install

To get started, visit the [Releases page](https://github.com/Ryder309/Team-blog-back-end/releases) to download the latest version of the software. You will find all available versions there.

## 🛠️ System Requirements

Before you download, ensure your system meets these requirements:

- **Operating System:** Windows, macOS, or Linux
- **Java Version:** Java 17 or higher
- **Disk Space:** At least 100 MB of free space
- **Internet Connection:** Required for authentication features

## 🔧 Installation Steps

1. **Download the Application**
   - Go to the [Releases page](https://github.com/Ryder309/Team-blog-back-end/releases). Find the latest version and click on the download link.

2. **Extract Files**
   - Once the download is complete, locate the downloaded ZIP or TAR file in your Downloads folder. 
   - Right-click the file and select "Extract All" (Windows) or "Unzip" (macOS/Linux). Choose a location on your computer to save the files.

3. **Open Command Line Interface**
   - On Windows, search for 'cmd' in the Start menu.
   - On macOS, open 'Terminal' from the Applications > Utilities folder.
   - On Linux, open your preferred terminal emulator.

4. **Navigate to the Application Folder**
   - Use the `cd` command to change the directory to where you extracted the files. For example:
     ```
     cd path/to/Team-blog-back-end
     ```

5. **Run the Application**
   - To start the API, type the following command and hit Enter:
     ```
     java -jar your-api-file.jar
     ```
   - Replace `your-api-file.jar` with the actual name of the JAR file you downloaded.

## 📈 Features

This API has several important functions to enhance your blog experience:

### 🔐 Authentication

- Users can register and log in using standard accounts or social logins via Google and GitHub.
- Manage user roles, such as `USER`, `ADMIN`, and `MODERATOR`.

### 👤 User Profile

- Retrieve the currently logged-in user's profile.
- Update personal information, including name, bio, location, and website.
- Upload and manage profile pictures.

### 📝 Blog Management

- Create and publish blog posts.
- Allow users to comment on posts and reply to comments in a threaded format.

### 📸 Media Handling

- Upload images for use in blog posts.
- Associate images with user accounts for profiles and posts.
- Set user avatars.

## 📊 Technologies Used

This API is built using the following technologies:

- Java 17+
- Spring Boot for web application development
- Spring Security for secure logins (JWT + OAuth2)
- Spring Data JPA with Hibernate for database interactions
- Relational databases including MySQL, PostgreSQL, and H2
- Java Mail for sending emails
- Mermaid for creating diagrams
